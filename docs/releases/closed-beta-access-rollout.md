# Closed-beta access rollout

This operational release marker requests the existing closed-beta access deployment workflow to run before Firebase Hosting is published.

Release invariants:

- Verified-email and explicitly allowlisted beta members may enter the general closed-beta application.
- Beta admission remains separate from genuine provider age-assurance records.
- Protected adult audio, manuscripts and other restricted material remain behind genuine age assurance.
- New Didit verification sessions remain paused for this rollout.
- Existing Didit integration, webhook processing and approval records remain preserved.
